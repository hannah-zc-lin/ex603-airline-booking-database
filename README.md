# ex603-airline-booking-database

## Project Summary
This project models a relational database for an airline booking that tracks passengers, flights, bookings, airports, and flight routes.

## Theme
Airline Booking

## Domain description
This project is about an airline booking system. The system should be able to answer questions such as: Which flight a passenger book? What flights are available? Where a flight depart and arrive? When did a passenger complete a booking, and how much did the ticket cost?

The database keeps track of passengers, flights, airports, and bookings information, while flight_routes connects flights to their departure and arrival airports.
